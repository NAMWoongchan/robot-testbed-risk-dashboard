## 웹에서 사용하기
[리스크 대시보드 열기](https://namwoongchan.github.io/robot-testbed-risk-dashboard/)

웹사이트와 로컬 파일의 저장소는 서로 다릅니다. 기존 로컬 파일에서 JSON 백업 → 웹사이트에서 JSON 복원으로 옮기세요. 복원은 현재 목록 전체를 교체하므로 기존 웹 데이터가 있다면 먼저 백업하세요. 서버에 데이터를 업로드하는 기능은 없으며, 각 브라우저에 저장됩니다. 공동 편집·다중 탭 동기화는 지원하지 않습니다.

## 배포와 업데이트
main은 코드·README·테스트·검증 보고서를 보관합니다. gh-pages는 index.html, styles.css, app.js, risk-core.js, sample-data.js만 게시합니다. main 변경만으로 사이트는 갱신되지 않습니다. 수정·검증 후 앱 5개를 gh-pages에 반영하고 Pages 배포 성공을 확인하세요.
# 프로젝트 리스크 대시보드

**index.html을 더블클릭하면 바로 사용할 수 있습니다.** 설치·서버·인터넷 연결은 필요하지 않습니다. HTML 파일이 편집기로 열리면 우클릭 → 연결 프로그램 → Microsoft Edge 또는 Chrome을 선택해 주세요.

## 처음 사용하기
1. [index.html](index.html)을 브라우저에서 엽니다.
2. 가상의 로봇 테스트베드 리스크 10건을 확인합니다.
3. **리스크 등록**으로 항목을 추가하거나 표의 **수정**으로 상세 내용·담당자·대응 계획을 변경합니다.
4. 확률(%)과 일정/비용 영향 등급을 입력하면 Risk Score가 자동 계산됩니다.
5. **JSON 백업**으로 전체 데이터를 내려받습니다. **JSON 복원**은 검증 후 현재 데이터를 전체 교체하며, 확인창에서 취소할 수 있습니다.

## 주요 기능
| 기능 | 동작 |
|---|---|
| 요약 지표 | 전체 미종료 건수, 심각 건수, 기한 초과 건수, 평균 점수 |
| 5×5 Risk Matrix | 미종료 항목을 P/I별 집계하며 칸을 누르면 표를 필터링 |
| 우선 대응 | 미종료 점수 내림차순·같은 점수는 기한순 상위 3건, 클릭 시 상세 수정 |
| Risk Register | 검색, 위험 등급/상태 필터, 점수/기한/ID 정렬, 추가·수정·삭제 |
| 저장 | 변경 시 localStorage 저장, 실패 시 메모리 모드와 백업 안내 |
| 백업/복원 | 전체 JSON 입출력, 버전·범위·필수값·날짜·중복 ID 검증 |
| 작은 화면 | 요약 2열, 패널 세로 배치, 등록부 안에서 좌우 스크롤 |

**요약·매트릭스·우선 대응은 항상 전체 미종료 기준이며, 검색/필터는 표에만 적용됩니다.** 표에는 기본적으로 종료 항목도 표시합니다. 종료 항목의 기존 점수는 보존되지만 요약에는 포함하지 않습니다.

## 평가 규칙
이 도구에서 정의한 **데모용 평가 기준**입니다. 공인 표준 또는 실제 사업의 합의된 평가 기준이라는 확인 가능한 근거 없음.

| 발생 확률 입력(Probability) | P 등급 |
|---|---:|
| 0~20% | 1 |
| 20% 초과~40% | 2 |
| 40% 초과~60% | 3 |
| 60% 초과~80% | 4 |
| 80% 초과~100% | 5 |

0%도 등급 1입니다. 0%를 점수 0으로 처리하는 모델이 아닙니다.

일정 영향은 **기준 일정 대비 지연 비율**, 비용 영향은 **기준 총예산 대비 추가 비용 비율**로 아래 등급을 직접 선택합니다. 원시 일정·금액을 입력받아 비율을 산출하는 기능은 없습니다.

| 영향 비율 | 일정/비용 등급 |
|---|---:|
| 0~1% | 1 |
| 1% 초과~3% | 2 |
| 3% 초과~5% | 3 |
| 5% 초과~10% | 4 |
| 10% 초과 | 5 |

**I = max(일정 영향 등급, 비용 영향 등급)**, **Risk Score = P × I**입니다. 1~4점 낮음, 5~9점 보통, 10~14점 높음, 15~25점 심각을 숫자·텍스트·색상으로 표시합니다. 예를 들어 발생 확률 75%, 일정 4, 비용 3이면 P4 × I4 = **16점·심각**입니다.

이 점수는 기대손실액이나 실제 발생 확률이 아닙니다. 안전·품질의 독립 영향도는 계산하지 않습니다. 특히 안전 리스크의 실제 대응 우선순위는 이 점수만으로 결정하지 않고 별도 검토해야 합니다.

기한 초과는 **종료가 아니며 대응 기한이 브라우저 로컬 날짜의 오늘보다 이전인 항목**입니다. 오늘 기한은 제외합니다. 날짜 변경은 최대 30초 후 또는 탭 복귀 시 반영합니다. 평균 점수는 전체 미종료 점수의 산술평균이며 0건이면 `—`입니다.

## 데이터와 저장
- 가상 샘플 10건의 고정 기한은 2026년 9월입니다. 실제 사업 데이터가 아니므로 시간이 지나면 기한 초과 건수는 달라집니다.
- 각 레코드는 고유 ID, 제목, 분류, 원인/결과 설명, 확률, 일정/비용 등급, 담당자, 대응 계획, 기한, 상태, 출처를 갖습니다. 상세 형식은 [계산 규칙](risk-core.js)을 참고해 주세요.
- 브라우저 저장은 브라우저·프로필·파일 위치 및 개인정보 설정에 영향을 받습니다. 파일 이동, 다른 브라우저 사용, 브라우저 데이터 삭제 전 **JSON 백업**을 해 주세요. 공동 편집·다중 탭 동기화 기능은 없습니다.
- 복원 파일은 최대 1MB, 1,000건, `schemaVersion: 1`과 `risks` 배열을 가져야 합니다. 빈 배열을 복원하면 전체 목록이 비워집니다. 먼저 백업해 주세요.
- 손상된 저장본 발견 시 원본을 자동 덮어쓰지 않고 샘플을 메모리에 표시합니다. JSON 복원을 명시적으로 실행하면 정상 데이터로 교체합니다. 저장 실패 때도 편집은 가능하지만 종료 전 백업이 필요합니다.
- 외부 통신, 사용자 계정, 서버 저장은 없습니다. 출처 필드는 사용자 텍스트로 보관하고 HTML로 실행하지 않습니다.

## 테스트 재실행(개발자용)
일반 사용에는 Node.js나 Playwright가 필요 없습니다. Node.js가 있으면 `node --test tests/core.test.cjs`로 순수 로직을 검증할 수 있습니다. 브라우저 테스트는 기존 설치된 Playwright를 `NODE_PATH`로 지정하고 `node tests/browser-test.cjs`를 실행합니다. 설치된 Microsoft Edge가 필요하며 서버는 사용하지 않습니다. 테스트는 격리된 브라우저 컨텍스트에서 수행하므로 평소 사용하는 브라우저 저장본에 영향을 주지 않습니다.
